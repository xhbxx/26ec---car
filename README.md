# 天猛星 MSPM0G3507 循迹小车

本工程为独立工程，不修改参考工程 `10_DC_MOTOR_PID_3`。当前只保留循迹开车所需功能：两路直流电机、编码器速度 PID、四路红外、ATK-MS6DSV、OLED 和按键。钢球控制、视觉串口通信及 EMM 步进电机驱动已全部删除。

## 接线

### TB6612 和直流电机

| 信号 | 天猛星引脚 |
|---|---|
| PWMA / PWMB | PA12 / PA13 |
| AIN1 / AIN2 | PA9 / PA8 |
| BIN1 / BIN2 | PA7 / PB13 |
| STBY | PB24 |

### 编码器

| 信号 | 天猛星引脚 |
|---|---|
| 左轮编码器 A 相 | PB8，上升沿中断 |
| 右轮编码器 A 相 | PB9，上升沿中断 |

编码器为 13 线、28:1 减速比，只读取 A 相上升沿，每个输出轴转一圈按 364 个脉冲计算，轮径为 65 mm。

编码器 PID 位于 `user_driver/motor.c`：定时器每 50 ms 读取左右轮脉冲，换算实际 RPM，与目标 RPM 比较后调整 PWM。参数位于 `user_driver/motor.h`：

```c
#define MOTOR_PID_KP (40)  /* 实际为 0.40 */
#define MOTOR_PID_KI (20)  /* 实际为 0.20 */
#define MOTOR_PID_KD (0)   /* 实际为 0.00 */
```

先调 `Kp`，再少量增加 `Ki`。OLED 的 `SET` 是目标轮速，`ACT` 是编码器实测轮速。

### 四路红外

| 信号 | 天猛星引脚 |
|---|---|
| IR1 | PA14 |
| IR2 | PB16 |
| IR3 | PB14 |
| IR4 | PB15 |

四路均为数字输入，低电平表示检测到黑线。红外不参与连续差速，只在整圈任务接近 A 点时确认终点横线。

### ATK-MS6DSV

| 信号 | 天猛星引脚 |
|---|---|
| SDA | PA16，独立软件 I2C |
| SCL | PA15，独立软件 I2C |
| SA0 | GND，地址 0x6A |

上电后保持车体静止约 0.8 秒。顺时针转动车体时 OLED 角度应为正，否则反转 `GYRO_Z_CLOCKWISE_SIGN`。

### OLED 和按键

| 功能 | 天猛星引脚 |
|---|---|
| OLED SDA / SCL | PA0 / PA1 |
| MODE | PA23，低电平有效 |
| START | PB18，低电平有效 |

启动页只显示模式选择。按 PA23 切换模式，按 PB18 开始；运行后显示左右轮 `SET/ACT`、IMU 状态和陀螺仪角度。

## Mode 2 控制逻辑

1. 目标是在 20 秒内完成一整圈并停车；编码器根据实际速度提前预测急刹位置。
2. AB、CD 直线距离分别由 `TRACK_STRAIGHT_MM` 和 `TRACK_CD_STRAIGHT_MM` 设置，陀螺仪分别保持 0 度和 180 度航向。
3. BC、DA 半圆各由编码器走满 1571 mm，固定轮速差负责转弯，陀螺仪跟踪 0→180→360 度并追加限幅修正。
4. 当前里程加预测刹车距离达到整圈目标时，直接将两轮目标速度设为 0 并使用 TB6612 短刹车，不进入低速接近阶段。

## Mode 4 控制逻辑

1. 目标是在 8 秒内完成 AB 直线，并尽量保持钢球位置。
2. 编码器计算直线距离，陀螺仪温和保持 0 度航向，不使用红外纠偏。
3. 到达 `TRACK_STRAIGHT_MM` 后任务完成，不再进入弯道，并采用平滑减速避免冲击钢球。

## Mode 5 控制逻辑

1. 目标是在 30 秒内完成一整圈，并尽量保持钢球位置。
2. 路径与 Mode 2 相同，但速度、加速度、转向差速和陀螺仪修正均更温和。
3. 红外只确认 A 点终点横线，未检测到时使用编码器整圈里程兜底。
4. 当前没有钢球传感器或主动控制，钢球稳定完全依靠平滑加减速、平滑转向和缓慢停车。

## 调参位置

- `car_config.h`：距离、速度、加减速度、红外和陀螺仪参数。
- `user_driver/motor.h`：编码器参数、轮径、最大转速及速度 PID。
- `TASK2_CURVE_STEERING_MMPS`：增大 Mode 2 转弯幅度，减小则更缓。
- `TRACK_STRAIGHT_MM`：AB 第一段直线距离，也用于 Mode 4。
- `TRACK_CD_STRAIGHT_MM`：Mode 2/5 的 CD 第二段直线距离。
- `GYRO_Z_CLOCKWISE_SIGN`：陀螺仪正方向，只在 `1` 和 `-1` 之间切换。

## 编译

1. CCS 导入本目录。
2. 打开并保存 `empty.syscfg`。
3. 执行 `Project -> Clean Project`。
4. 执行 `Project -> Build Project`。

环境：MSPM0 SDK 2.10.00.04、SysConfig 1.26.2、MSPM0G3507 LQFP-64。
